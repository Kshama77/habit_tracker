# HabitTracker

A simple beginner-friendly Java console application for tracking daily habits and their completion status.

## Features

- Add habits
- View all habits
- Mark habits as complete
- Mark habits as incomplete
- Edit habits
- Delete habits
- View completion progress
- Simple menu-based console interface

## Java Concepts Used

- Classes and objects
- Constructors
- Encapsulation
- Private fields
- Getters and setters
- `ArrayList`
- `Scanner`
- `for` loops
- `if/else`
- `switch`
- Methods
- Basic exception handling
- Basic percentage calculation

## How to Run

Make sure Java is installed.

From the project folder:

```bash
javac -d out src/Habit.java src/HabitTracker.java
java -cp out HabitTracker
```

## Example Habits

You can add habits such as:

- Drink Water
- Exercise
- Read
- Study Java
- Walk
- Sleep 8 Hours

## Note

This is intentionally a basic Java project. Data is stored only while the application is running. Closing the application clears the habits.
